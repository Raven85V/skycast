# Беспроводной датчик для SANTON METEO

Прошивка для ESP8266 (Wemos D1 mini) или ESP32. Сама находит подключённые датчики и раз в минуту отправляет показания на станцию по Wi-Fi.

## Что находит само
- **BME280** (температура, влажность, давление) и **BMP280** (температура, давление) на I2C, адреса 0x76 и 0x77. Можно два датчика на одной шине (по одному на каждый адрес), на ESP32 ещё два на второй шине.
- **DS18B20** на одном проводе (OneWire), до 6 штук.
- Названия по порядку: `bme1`, `bme2`, `bmp1`, `ds1`, `ds2`... (DS18B20 нумеруются по возрастанию адреса, поэтому номера не прыгают).

## Подключение
| | ESP8266 (D1 mini) | ESP32 |
|---|---|---|
| I2C SDA / SCL | D2 / D1 (GPIO4 / 5) | GPIO21 / 22 |
| 2-я шина I2C (необяз.) | нет | GPIO25 / 26 |
| DS18B20 (данные) | D5 (GPIO14) | GPIO4 |

Питание датчиков 3.3 В. DS18B20: резистор 4.7 кОм между линией данных и 3.3 В. Пины меняются в `src/config.h`.

## Запуск
1. Откройте `src/config.h`: имя и пароль Wi-Fi, IP станции (он виден внизу экрана), имя датчика `DEVICE_ID`, при желании ключ.
2. `pio run -e esp8266 -t upload` или `pio run -e esp32 -t upload`.
3. Откройте на станции страницу `http://IP_станции/settings/sensors`: через минуту там появятся найденные датчики. Дайте им названия («Улица», «Балкон»), включите показ в бегущей строке, при необходимости задайте поправки.

## Питание от батареи
В `config.h` поставьте `DEEP_SLEEP 1`. Датчик будет просыпаться, отправлять данные и засыпать. На ESP8266 соедините D0 (GPIO16) с RST. Интервал `SEND_INTERVAL_S`: 300 секунд и больше сильно продлевают жизнь батареи (не забудьте, что на станции значение гаснет, если датчик молчит дольше времени, заданного на странице датчиков, по умолчанию 15 минут).

## Формат (если захотите писать свой датчик)
`POST http://IP/api/sensor`, тело JSON:
```
{"id":"ulica","k":"ключ","rssi":-60,"s":[{"n":"bme1","t":12.3,"h":65,"p":1013.2},{"n":"ds1","t":11.8}]}
```
t - °C, h - %, p - гПа; любое поле можно опустить. Простой вариант без JSON: `GET /api/sensor?id=ulica&n=bme1&t=12.3&h=65&p=1013.2&k=ключ`.
